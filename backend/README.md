# Бэкенд

Laravel 13 + Sanctum 4, SQLite. API и парсер Яндекс.Карт.

Обзор проекта, запуск через Docker и ответы по дополнительным требованиям — в [README проекта](../README.md). Здесь — техническая часть.

## Запуск и команды

Нужен PHP ≥ 8.3.

```bash
composer setup                      # зависимости, .env, ключ, база, сид-пользователь
php artisan serve --host=127.0.0.1 --port=8000
```

```bash
php artisan test                    # 75 тестов, без сети
php artisan test --group=live       # 2 теста против настоящего Яндекса
php artisan yandex:parse "<ссылка>" # разобрать карточку и показать результат
php artisan yandex:parse-all        # поставить в очередь разбор всех организаций
vendor/bin/pint                     # стиль кода
```

Фоновый режим: `QUEUE_CONNECTION=database` в `.env` плюс `php artisan queue:work --tries=3`. Код при этом не меняется — и API, и фронт работают через поле `status`.

## Как устроен парсер

### Шаг 1. Карточка

Страница организации отдаётся обычным HTTP-запросом с браузерным `User-Agent`, без капчи. Внутри — два полезных блока.

**SSR-состояние** в `<script type="application/json" class="state-view">` — это и данные, и ключи от API:

```
config.csrfToken                       → нужен для запросов к API
config.counters.analytics.sessionId    → нужен для запросов к API
stack[0].results.items[0].title        → название
stack[0].results.items[0].address      → адрес
stack[0].results.items[0].ratingData   → рейтинг и оба счётчика
```

`ratingData` содержит ровно те три числа, которые требует задание, уже разделёнными:

```json
{ "ratingValue": 4.900000095367432, "ratingCount": 21220, "reviewCount": 5858 }
```

`ratingCount` — сколько людей поставили оценку, `reviewCount` — сколько из них написали текст. `ratingValue` приходит с шумом двойной точности, поэтому округляется до одного знака.

**Микроразметка schema.org** дублирует те же три числа в `<meta itemProp="ratingValue|ratingCount|reviewCount">`. Парсер читает состояние, а микроразметку держит запасным вариантом: два независимых источника заметно снижают шанс, что агрегаты отвалятся целиком.

### Шаг 2. Подпись запроса

Отзывы отдаёт `GET /maps/api/business/fetchReviews`. С одними `businessId`, `csrfToken` и `sessionId` он отвечает **400 с пустым телом** — не хватает параметра `s`.

Алгоритм нашёлся в клиентском бандле карт (`chunks/base/*.js`), в общем транспорте всех запросов к `/maps/api/*`:

```js
var t = qs.stringify(e, { sort: caseInsensitiveCompare });
for (var r = 0, n = 5381; r < t.length; r++) n = 33 * n ^ t.charCodeAt(r);
return String(n >>> 0);
```

Параметры сериализуются с ключами, отсортированными по алфавиту **без учёта регистра**, кодируются по RFC 3986, и от строки считается djb2-xor в 32-битной беззнаковой арифметике.

Перенос на PHP — [`ReviewsRequestSigner`](app/Services/Yandex/ReviewsRequestSigner.php). RFC 3986 в PHP это в точности `rawurlencode`, а строка после процентного кодирования всегда ASCII, поэтому побайтовый `ord()` эквивалентен `charCodeAt()` над UTF-16.

Алгоритм закреплён юнит-тестом с контрольным вектором, снятым с живого запроса, который Яндекс принял:

```
ajax=1&businessId=1124715036&csrfToken=…%3A1789151481&locale=ru_RU
&page=1&pageSize=50&ranking=by_time&sessionId=…          →  s = 3006753564
```

Если этот тест упадёт, а остальные останутся зелёными — разъехались не внутренности приложения, а совместимость с Яндексом.

### Шаг 3. Обход страниц

Цикл по 50 отзывов на запрос с паузой между страницами.

**Яндекс жёстко обрезает выдачу на 600 отзывах.** Проверено на организациях с 5858, 2632, 1391 и 778 отзывами — во всех случаях приходит ровно 600 (12 страниц), тринадцатая пустая. Организация со 145 отзывами отдаётся целиком, обход останавливается сам.

Отдельная ловушка: `data.params.totalPages` рапортует полное число страниц (118 для первой карточки) и до конца досчитать не даёт. Единственный надёжный признак конца — **пустая страница**.

### Две тонкости, подсмотренные у клиента Яндекса

- если в ответе пришёл новый `csrfToken` — старый протух, запрос повторяется **один раз** с новым;
- если в ответе `type == "captcha"` — включилась защита от ботов, это отдельная ошибка.

### Куки

Карточка и API ходят через **один cookie-jar**: Яндекс выдаёт на первой странице набор кук, и без них API отвечает 400 даже с корректной подписью. Поэтому `YandexMapsClient` зарегистрирован как `scoped` — один экземпляр на весь проход.

## Обработка ошибок

Каждый сбой превращается в осмысленный ответ `{ "message": "...", "code": "..." }`:

| Ситуация | Код | HTTP |
|---|---|---|
| Ссылка не на карточку организации | `invalid_url` | 422 |
| Страница недоступна, карточка удалена | `organization_unavailable` | 502 |
| Не нашлось нужных данных на странице | `markup_changed` | 502 |
| Пустой или неразбираемый ответ API | `empty_response` | 502 |
| Капча | `captcha` | 503 |
| 403 или 429 — придержали адрес | `blocked` | 503 |
| Таймаут, обрыв связи | `request_failed` | 504 |

Сбои парсинга не «роняют» запрос: они записываются в организацию (`status`, `error_message`), и у фронта остаётся одно правило — смотреть на `status`.

## База данных

**organizations** — карточка и агрегаты: `yandex_id` (уникальный), `name`, `address`, `rating`, `ratings_count` (**оценки**), `reviews_count` (**отзывы**), `fetched_reviews_count` (сколько реально выгружено, ≤ 600), `status`, `error_message`, `parsed_at`.

**reviews** — автор, дата, текст, оценка. Уникальный ключ `(organization_id, yandex_review_id)` обеспечивает идемпотентный `upsert`, индекс `(organization_id, published_at)` — постраничную выдачу.

**organization_snapshots** — история агрегатов, строка пишется только при изменении значений.

**users** — поле `organization_id`: ссылка, сохранённая пользователем.

## API

Аутентификация — сессионная кука Sanctum (SPA-режим). Перед первым POST фронт запрашивает `GET /sanctum/csrf-cookie`.

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/login` | вход, не более 6 попыток в минуту |
| POST | `/api/logout` | выход |
| GET | `/api/user` | текущий пользователь |
| GET | `/api/organization` | сохранённая организация или `null` |
| POST | `/api/organization` | сохранить ссылку и разобрать карточку |
| POST | `/api/organization/refresh` | перечитать данные |
| GET | `/api/organization/reviews?page=N` | отзывы, по 50 на страницу |

Принимаются ссылки в любом виде: со слагом и без, с `/reviews/`, с query-хвостом, зеркала (`.com.tr/harita/…`, `.kz`, `.by`, `.uz`), `/profile/{id}`, выдача поиска с `?oid=`, короткие ссылки «Поделиться» (разворачиваются редиректом) и адрес без протокола. Любая приводится к каноническому виду.

## Где что лежит

| Путь | Что это |
|---|---|
| `app/Services/Yandex/` | весь парсер: клиент, разбор страницы, подпись, обход страниц |
| `app/Jobs/ParseOrganizationJob.php` | парсинг, повторы при сбое, идемпотентное сохранение |
| `app/Console/Commands/` | `yandex:parse` и `yandex:parse-all` |
| `app/Http/Controllers/Api/` | контроллеры: только валидация и постановка задачи |
| `config/yandex.php` | таймауты, ретраи, размер страницы, паузы, пул UA, прокси |
| `database/migrations/` | organizations, reviews, snapshots, связь с пользователем |
